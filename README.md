# 🛒 SmartCart AI

SmartCart AI is an AI-powered grocery price comparison platform that helps users find the cheapest combination of products across multiple quick-commerce platforms.

Currently supported:

- Blinkit
- Zepto

The application automatically searches products, matches equivalent items across platforms, and recommends the lowest-cost option.

---

## 🚀 Features

- 🔍 Search groceries across multiple platforms
- ⚡ Live scraping using Playwright
- 🧠 Intelligent product matching
- 💰 Cheapest price recommendation
- 🛍️ Smart cart optimization
- 🌐 REST APIs built using Express.js
- ⚛️ React frontend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/nisarga-na/SmartCartAI.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
